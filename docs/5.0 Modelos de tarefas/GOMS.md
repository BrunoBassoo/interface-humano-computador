Se quiser analisar um período amplo.

# GOAL 0: Gerar Relatório Individual

## GOAL 1: Emitir relatório de desempenho do usuário

### METHOD 1.A: Gerar relatório
- O1: Acessar área de relatórios
- O2: Selecionar usuário
- O3: Selecionar período
- O4: Escolher formato
- O5: Clicar em gerar
- O6: Baixar arquivo

**SEL. RULE:**  
Se quiser visualização estruturada → selecionar PDF.  
Se quiser análise estatística → selecionar CSV.
