# Leitura do MOLIC — contribuições

| Aspecto da conversa | Conteúdo |
|---------------------|----------|
| **Negociação inicial de modo** | Treino/predição como condição de entrada da conversa técnica |
| **Confirmação e fila** | Resposta que reduz incerteza após o compromisso do usuário com o arquivo |
| **Processamento e retorno** | Turno de sistema que antecipa comparação de evidências |
| **Ruptura e retomada** | Nó de falha → novo envio, como governança de erro sem encerrar o diálogo |
