# Protótipo navegável — escopo

O protótipo implementa, em **HTML/CSS/JavaScript** estático, o mapa de navegação principal: autenticação simulada, upload com estados fictícios, painel “Minha análise” (real × IA), relatórios, visão administrativa agregada e página institucional. O objetivo é sustentar discussões de layout, hierarquia de informação e vocabulário na interface antes da integração completa com o *backend* de processamento de vídeo.

**Execução local:** abrir `index.html` do repositório `bvrai-interface` no navegador.
